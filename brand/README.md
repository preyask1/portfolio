# In the Loop

The personal mark of Preyas Kulshrestha. An open loop (the workflow) with an orange node working inside its gap
(AI put to work inside the process, not bolted on).

## Files

| File | Use |
|---|---|
| `in-the-loop.svg` / `in-the-loop-512.png` | Dark mark on light backgrounds |
| `in-the-loop-white.svg` / `in-the-loop-white-512.png` | White mark on dark backgrounds |
| `in-the-loop-avatar.svg` / `in-the-loop-avatar-1024.png` | Profile picture or social avatar (LinkedIn, GitHub) |

The website does not load these files. Its logo and favicon are built into `index.html`.

## Colours

| Name | Hex |
|---|---|
| Signal orange | `#FF7A1A` |
| Ink | `#0A0A0A` |
| White | `#FFFFFF` |
| Background | `#000000` |

## Usage

- Keep the orange node orange. The loop is ink on light backgrounds and white on dark ones.
- Leave clear space around the mark of at least the node's diameter.
- Smallest size: 16 px on screen.
- Do not rotate the mark, close the gap or move the node out of it.
- Typeface used alongside it on the site: Poppins 500, lowercase, e.g. "preyas kulshrestha." with an orange full stop.
