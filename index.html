What it does

  • Verifies reported bugs and traces impact across 4 product repos
  • Writes implementation plans
  • Runs read-only SQL and DAX tests on live data, headless and unattended

How it is built

  • Hexagonal core with about 20 typed ports and 15 skills
  • 7 entry points: React web UI, Slack, Microsoft Teams bot, email, MCP server, FastAPI HTTP API, 33-command CLI
  • Connected to Jira, Microsoft Fabric, Power BI, Databricks, Azure DevOps and Azure Data Factory
  • Runs on Azure Container Apps with Blob Storage, Cosmos DB and Azure Managed Redis

How it stays safe

  • Entra ID on every call, least-privilege service principals, secret redaction and a query governor
  • Read-only allowlist (SELECT, WITH, DESCRIBE, SHOW, one statement per call), tool scope locked in a PreToolUse hook
  • Evaluation loop records real test results, confidence-scored verdicts and human reviews

Impact

  • First 3 weeks live: supported 4 new Power BI reports, investigated about 50 bugs across UAT and post-go-live, caught 5 pipeline failures, alerting affected users and investigating root cause
  • 20 users across developer and business teams, scale-up to 50 planned
  • Replaced two laptop-bound agents; profiling cut opening steps from ~2 min to ~2 s
Result

635-test suite · ~2 min → ~2 s · Runs unattended on live production data
