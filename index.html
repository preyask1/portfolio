Case 01

Scotri: Read-Only AI Engineering Agent

  • Agentic AI
  • Solo Build
  • Production Data

Designed and built a shared, read-only AI agent on the Claude Agent SDK, deployed on Azure App Service and connected to Jira, Microsoft Fabric, Power BI, Databricks, Azure DevOps and Azure Data Factory. It verifies reported bugs, traces impact across 4 product repos, writes implementation plans and runs read-only SQL and DAX tests on live data, headless and unattended. A hexagonal core with about 20 typed ports and 15 skills sits behind 7 entry points: a React web UI, Slack, a Microsoft Teams bot, email, an MCP server, a FastAPI HTTP API and a 33-command CLI. Entra ID on every call, least-privilege service principals, secret redaction, a query governor and a read-only allowlist (SELECT, WITH, DESCRIBE, SHOW, one statement per call), with tool scope locked in a PreToolUse hook, keep it safe on production. Its evaluation loop records real test results, confidence-scored verdicts and human reviews. It replaced two laptop-bound agents, and profiling cut its opening steps from about 2 minutes to about 2 seconds. In its first 3 weeks live it supported delivery of 4 new Power BI reports, investigated about 50 bugs across UAT and post-go-live, and caught 5 pipeline failures, alerting affected users and investigating root cause. Today 20 users across developer and business teams rely on it, with a scale-up to 50 planned.

Result

635-test suite · ~2 min → ~2 s · Runs unattended on live production data
